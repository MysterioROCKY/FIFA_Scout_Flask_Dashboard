DATA QUALITY

How this app handles data

A local snapshot, not live scraping

The dashboard reads data/fifa_players_cleaned.csv. It never sends visitors' requests to SoFIFA or any other third party.

What was improved

  • Player rows are de-duplicated by name and team.
  • Currency values are stored as numbers, not text.
  • Hits is intentionally absent: it is site engagement, not goals scored.
  • The optional scraper uses HTML selectors, request timeouts, a clear user-agent, and a pause between pages.

Snapshot notice

The bundled starter data is drawn from examples visible in the original notebook and is dated 2020-12-01. Run python scraper.py only after checking the source's current robots.txt and terms; review the resulting dataset before publishing it.
